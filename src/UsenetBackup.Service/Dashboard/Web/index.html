Tools

Retention check
STAT-sample articles against provider retention; repost aging ones with fresh IDs. Runs across every configured repository.
Download from NZB
Fetch chunks referenced by an NZB file from Usenet into the first configured repository.
Sync to SMB share
Copy every repository's chunks and manifests to a network share (e.g. a NAS). Idempotent — files already on the share are skipped.
Password: uses the job's saved SMB password, or set USENETBACKUP_SMB_PASSWORD.
LAN server
Serve every configured repository's chunks over HTTP for LAN restores (e.g. from WinRE recovery).
